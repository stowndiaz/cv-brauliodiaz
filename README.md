# Braulio Diaz - Personal Site

Sitio personal y portafolio de Braulio Diaz, disenador grafico con experiencia en frontend, UX/UI, motion graphics, publicidad y herramientas digitales.

La intencion del proyecto es construir una experiencia web cuidada, rapida e interactiva que funcione como presentacion profesional y como pieza de portafolio.

## Objetivo

Mostrar de forma clara:

- Quien es Braulio.
- Que sabe hacer.
- Donde ha trabajado.
- Que proyectos ha creado.
- Como contactarlo rapidamente.

## Secciones

- Home.
- Curriculum vitae.
- Portafolio / book.
- Proyectos personales.
- Contacto.

## Direccion de diseno

La interfaz toma como base una composicion limpia y editorial: fondo claro, texto negro, acento naranja, bordes marcados, mucho espacio negativo y microinteracciones cuidadas.

El sitio debe sentirse mas cercano a una interfaz viva que a una pagina estatica. En desktop se priorizan vistas contenidas dentro del viewport cuando sea razonable, sin romper responsive ni accesibilidad.

## Principios de desarrollo

- Avanzar de forma incremental.
- Reutilizar los assets reales disponibles en `static/`.
- Mantener animaciones rapidas, reversibles y no bloqueantes.
- Respetar `prefers-reduced-motion`.
- Evitar dependencias pesadas para interacciones simples.
- Cuidar rendimiento, responsive y accesibilidad basica.

## Assets

Los archivos publicos del sitio viven en `static/`.

Los mockups de referencia son material de trabajo local y no deben subirse al repositorio.
